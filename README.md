# AI Job Tracker Frontend 💼

Frontend for an AI-powered job application tracking platform with Gmail synchronization and application workflow management.

---

## 🌐 Live Demo

Frontend: https://job-tracker-application-psi.vercel.app

Backend API: https://jtb-parser.onrender.com

---

## 🚀 Features

- 🔐 JWT Authentication
- 🔑 Google OAuth Login
- 📧 Gmail Synchronization UI
- 📊 Job Tracking Dashboard
- 📌 Application Status Management
- ⚡ Responsive Interface

---

## 🛠️ Tech Stack

- React.js
- Vite
- Axios
- React Router
